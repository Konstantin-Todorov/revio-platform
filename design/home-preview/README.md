# Official marketing homepage concept

Local visual prototype, NOT documentation and NOT a live deployment. Source website remains unchanged in the sibling revio-websites repository. Existing logo and screenshots copied from its public assets.

Run from platform root: `python3 -m http.server 3011 --bind 127.0.0.1 --directory design/home-preview`.

Review: larger hero/product screenshots, Product vs Browser frame toggle, four-product accessible tab switcher, mega menu, scroll reveals, finite replayable shared-record animation, accordions, mobile layout and reduced-motion fallback. Navigation to demo/pricing/product details links to the existing official site; forms are not duplicated.

No customer logos, testimonials, ratings, invented performance figures or unverified provider support added. Workflow illustration is explicitly not live telemetry. Copy is proposed, not approved commercial language. After review, port selected sections into the marketing site's own framework, rather than replacing its app with this static prototype. Google Fonts is used in the preview; production should reuse/self-host the site's font assets.

All files intentionally uncommitted pending founder design review.
