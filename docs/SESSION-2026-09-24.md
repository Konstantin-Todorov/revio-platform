## 4. Rules this session added — read before changing these areas

1. **Client components take strings only.** A dictionary function passed as a prop makes Next refuse
   the page. Use `{name}` templates filled with `fill()`, or word it on the server.
2. **A message from `@revio/db` or `@revio/core` gets a stable `code`** (`RegisterProblemCode`,
   `TwoFactorErrorCode`, `WelcomeWriteCode`); the screen says `strings[code] ?? message`. Never
   translate by matching English.
3. **Where core writes English copy, a drift test holds the UI's English to it word for word**
   (`apps/pms/lib/i18n/welcome-drift.test.ts` — welcome steps and the PMS setup checklist).
4. **Times are the property's zone.** Anything formatted with `toISOString()` or without `timeZone`
   is UTC in production — three hours behind a Bulgarian hotel.
5. Every commit went through `pnpm verify` first; production was checked after deploys
   (`AppError` empty; the Bulgarian sign-in served from pms.reviosoft.app).
